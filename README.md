# scoophash

Scoop encode/decode helpers for hash payloads in pipelines.

**Site:** https://theworker02.github.io/scoophash/

## Install / run

```bash
git clone https://github.com/theworker02/scoophash.git
cd scoophash
node src/cli.js
node --test
```
